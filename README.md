# AI Air Sketch to Realistic Image Generator

## Overview

AI Air Sketch to Realistic Image Generator is a Computer Vision and Generative AI project that allows users to draw objects in the air using hand gestures and automatically generate realistic images using ControlNet and Stable Diffusion.

## Features

* Real-time hand tracking using MediaPipe
* Air drawing using OpenCV
* Automatic sketch capture
* Sketch-to-image generation using ControlNet
* Realistic image generation using Stable Diffusion
* End-to-end AI pipeline

## Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy
* ControlNet
* Stable Diffusion
* Diffusers
* Hugging Face

## Workflow

Air Drawing → Sketch Capture → ControlNet → Stable Diffusion → Realistic Image
